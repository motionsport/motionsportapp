# Motion Gym — Frontend

Next.js 16 App Router PWA. Backend API runs on port 3001 (proxied via `/api` rewrites in `next.config.ts`).

- **Where a component goes**: used by one page → a file next to that `page.tsx` (no `_components` folder); used by several pages → `components/<domain>/`, like the backend's modules. Don't put files in the root of `components/`
- `components/` — `ui/` (`Header`, `MotionGymLogo`, `PageLayout`, `GymLoader`, `Badge`, `Modal`, `WarnNote`), `pwa/` (`SwRegister`, `OfflineBanner`: sticky "Немає інтернету" strip after 5 s offline, in `app/layout.tsx`), `auth/LoginForm` (member login / «Вхід для команди»: trainer username or owner email, then home by role, `lib/loginRedirect.ts`), `prices/PriceList`, `schedule/` (`BookingBadge`: the day's booking state, the same on the home page and the trainer's panel, «Запис відкрито» / «Запис закрито» / «Запис на ранкове групове відкриється сьогодні о 16:00»; `CancellationReasonModal`, `SlotCard`: group slot; «Запис відкриється сьогодні / завтра / 29.11 о HH:MM» (counted from today) from the slot's own `bookingOpenAt` (`lib/bookingOpens.ts`), «Запис закрито» once `slot.started`; without a group pass «Записатись» opens `GroupPassModal`: single visit / pass online, by transfer or cash (whatever `methods` allows); on the member's own booking «+ Привести гостя» → name → «Додати гостя», then «Гість: Ім'я» with «Прибрати»; guests appear in the trainer's lists indented right under the member, with a «гість» badge and their own ✓/✗, `api.updateParticipantAttendance` picks the route; `AssignedSlotCard`: personal / split, booked by the trainer; «Залишилось N тренувань» or «Оплатити» → `/purchases` (not once it has started: then only «Тренування вже почалося»); with a package but no club card that day (`hasCard`) a `WarnNote` «На цей день у вас немає абонемента в зал» and «Купити абонемент» → `/purchases?buy=card` (the club card choice), or «Абонемент діє до 10.12. Новий можна купити, коли він закінчиться.» (`cardEndsOn`)), `ui/BurgerMenu` (the team's burger: links + «Вийти» to the team login), `owner/OwnerMenu` (Статистика залу / Повернення · N / Ціни / Тренери / Клієнти / Мій пароль), `stats/` (`RevenueRows`: a card's money, columns at price list prices → «Разом», discounts, refunds → «Фактично отримано»; `PeriodSwitch`, `MonthStepper`: trainer and owner stats), `admin/AdminMenu` (`BurgerMenu` in the header of every trainer page: Панель тренера / Клієнти / Календар / Розклад групових / Історія / Статистика / Ціни / Мій пароль / Вийти, same on phone and desktop), `admin/SlotCard` (a participant of a personal / split training without a gym card that day: warn badge «немає абонемента», also in the calendar modal), `admin/AttendanceButton` (— → ✓ → ✗ toggle, today page and history), `admin/CancellationList` (who cancelled/moved and why: today page, calendar modal, client history), `admin/ClientParts`. UI words (see «Words: code ↔ UI» in the root CLAUDE.md): a club card is «Абонемент (клубна карта)» in headings, «абонемент» in short labels; trainings bought are «пакет»; never just «карта»
- `lib/api.ts` — typed fetch wrapper for all backend calls; its types live in `lib/apiTypes.ts` and are re-exported, so import them from `@/lib/api`
- `lib/trainingTypes.ts` — training types come from the API as `group` | `personal` | `split`; `TYPE_COLORS` (calendar, history) and the Ukrainian words `TYPE_LABEL` / `TYPE_LABEL_PLURAL`. Never show the raw value
- `lib/liqpay.ts` — `submitLiqPay(checkout)` (form POST to LiqPay); prices come from the API, nothing hard-coded

Page container (`max-w-xl`, `px-5`) is defined once in `app/layout.tsx`. `PageLayout variant="top"` adds the bottom padding (`3rem` + the iPhone safe area); centered pages have none. Pages return content directly without wrapper `<main>` tags.

Routing by role: `proxy.ts` by the `role` cookie, rules in `lib/roleRoutes.ts` (see «Routing by role» in the root CLAUDE.md). `/` is a server `page.tsx` that passes `signedIn` to the client `SchedulePage.tsx`
